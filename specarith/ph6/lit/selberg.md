**Bottom line.** BS07 Theorem 3, eq. (2.39), is an explicit, numerically vetted trace formula for the
**even and odd sectors separately** of Γ0(N) with N squarefree. N = 1 is PSL(2,Z). It is the
primary source for items 1, 3 and 5. BL16 (eq. (2.5) at n = ±1, from Strömbergsson 2016) is a second
statement of the same formula in Hecke-operator form, with T_{-1} = the parity operator. I checked
algebraically and numerically that the two agree on (even + odd) and on (even − odd); see §3.4.

## 1. The complete Selberg trace formula for PSL(2,Z)

### 1.1 Fourier convention and admissible h (QUOTED, BS07 Theorem 2, p. 13)

> Let h(r) be any function satisfying (a) h(r) is analytic on |Im r| ≤ 1/2 + δ for some δ > 0;
> (b) h(−r) = h(r); (c) |h(r)| ≤ A (1 + |Re r|)^{−2−δ}. Set
> **g(u) = (1/2π) ∫_{−∞}^{∞} h(r) e^{−iru} dr**. Then the formula (2.37) holds, where the various
> sums and integrals are all absolutely convergent.

BL16 uses the same pair: h(r) = ∫_R g(u) e^{iru} du (Prop. 2.1, with g(u) = q(sinh²(u/2))).
The spectral side runs over the **whole discrete spectrum, including λ = 0**: BS07 p. 3, "0 ≤ λ1 ≤ λ2 ≤ …,
r_n = sqrt(λ_n − 1/4) ∈ R+ ∪ i[−1/2, 0]". So the constant eigenfunction contributes h(i/2) on the left.
In BL16 the left side is Σ_{λ∈R≥0} Tr T_n|A(1,λ) h(sqrt(λ−1/4)).

> **Caveat for G1.** h must be **even** and analytic in the strip. A raw S(τ) = Σ_j w(r_j) e^{iτ r_j}
> is not of this form. Only its even part (h(r) = w(r) cos(τ r) for even w) is covered, and the trivial
> eigenvalue r = i/2 must be added to the spectral side with weight h(i/2).

### 1.2 General formula with reflections: BS07 eq. (2.37), pp. 12–13 (QUOTED, structure)

Setting: Γ ⊂ G = PGL(2,R) cofinite, Γ+ = Γ ∩ G+ ≠ Γ, χ a unitary character of Γ. The space is
L²(Γ\H, χ) = { f : f(Tz) = χ(T) f(z) for all T ∈ Γ }, where T ∈ G with ad − bc < 0 acts by
z ↦ (a z̄ + b)/(c z̄ + d) (p. 3). Then

```
Σ_{n≥1} h(r_n) = μ(Γ\H)/(4π) ∫ r h(r) tanh(πr) dr
 + Σ_{{T}⊂M, non-ell}  log N(T0)/[Z_Γ(T):[T0]] · χ(T) g(log N(T)) / ( N(T)^{1/2} − sgn(det T) N(T)^{−1/2} )
 + Σ_{{T}⊂M, elliptic} χ(T)/( 2|Z_Γ(T)| sin θ(T) ) ∫ e^{−2θ(T) r}/(1+e^{−2πr}) h(r) dr
 + ( Σ_{j∈C, k(j)=j} χ(T_{j0}) ) { (1/8) h(0) + (1/4π) ∫ h(r) ( Γ'/Γ(1/2+ir) − Γ'/Γ(1+ir) ) dr }
 + (g(0)/4) Σ_{<j,v>∈H} χ(T_{jv}) log c_{jv} + (g(0)/2) Σ_{1≤j≤κ, j∉C} log 1/|1−χ(T_j)|
 + (|C|/2) { (1/4) h(0) − g(0) log 2 − (1/2π) ∫ h(r) Γ'/Γ(1+ir) dr }
 + (1/4π) ∫ h(r) (φ^Γ)'/φ^Γ (1/2+ir) dr − (1/4) h(0) Tr Φ^Γ(1/2)       [omit if R_{Γ,χ} = ∅]
```

The denominator N^{1/2} − sgn(det T) N^{−1/2} is the source of the **reflection-term sign
structure**: glide reflections (det T < 0) get N^{1/2} + N^{−1/2}.

### 1.3 Explicit formula for Γ0^±(N): BS07 Theorem 3, eq. (2.39), pp. 14–15 (QUOTED)

Γ = Γ0^±(N) = { (a b; c d) : a,b,c,d ∈ Z, ad − bc = ±1, N | c } (2.38), with the character
χ((a b; c d)) = (ad − bc)^ε χ(d), ε ∈ {0,1}. The reflection is V = (−1 0; 0 1), and χ(V) = (−1)^ε (p. 14).
V acts as z ↦ −z̄, so **ε = 0 is the even sector (f(−z̄) = f(z)) and ε = 1 is the odd sector**.

```
(2.39)  Σ_{n≥1} h(r_n) = ( Π_{p|N}(p+1) / 24 ) ∫ r h(r) tanh(πr) dr
   + (1/2) Σ_{n∈{−1,1}} n^ε  Σ_{t∈Z, sqrt(t²−4n)∉Q}  <χ(δ)>_{δ²−tδ+n≡0}
        · ( Σ_{f|ℓ} h+(r[f]) · [r[1]^1 : r[f]^1] · Π_{p|N} {2 if p|f ; 1+(d/p) if p∤f} ) · A(t,n)
   − (d(N)/4) g(0) ( log(8N) + C_{χ,ε} log( N q(χ)/(2π²) ) + (1/2)(C_{χ,ε} − 1) log(N,2) )
   − (d(N)/4π) ∫ h(r) ( Γ'/Γ(1/2+ir) + C_{χ,ε} Γ'/Γ(1+ir) ) dr + [ if χ≠1: C_{χ,ε} d(N) h(0)/8 ]
   + d(N) Σ_{n≥1} Λ(n) {χ}_ε(n)/n · g(2 log n) − (d(N)/2) Σ_{p | N/q(χ)} Σ_{m≥1} (log p) {χ}_ε(p^m)/p^m · g(2 log p^m)
```

with (p. 15): t² − 4n = dℓ², d a fundamental discriminant, ℓ ∈ Z+; r[f] = Z + fωZ, ω = (d + sqrt d)/2;
r[f]^1 its norm-one unit group; h+(r[f]) the narrow class number of r[f];

```
(2.40)  A(t,n) = log ε1 / sqrt(t²−4n) · g( log( (|t| + sqrt(t²−4n))² / 4 ) )              if t²−4n > 0
        A(t,n) = 2 / ( |r[1]^1| sqrt(4−t²) ) · ∫ e^{−2r·arccos(|t|/2)} / (1+e^{−2πr}) h(r) dr   if t²−4n < 0 (thus n=1)
```

where ε1 is "the proper fundamental unit in Q(sqrt d)". BL16 writes the same quantity as ε_d^+, "the
smallest unit with norm 1, i.e. the fundamental unit when it has norm 1 and its square otherwise".
d(N) is the number of divisors of N, and

```
(2.41)  C_{χ,ε} = 1 if χ not pure ; 2 if χ pure, ε = 0 ; 0 if χ pure, ε = 1 ;
        {χ}_ε(δ) = (2/d(q(χ))) Σ_{A|q(χ), χ_A(−1)=(−1)^ε} χ^{(A)}(δ).
```

χ is *pure* if χ_p(−1) = 1 for every p | N. BS07 p. 15 says the parabolic lines summed over ε "agree with
[Hejhal Vol. 2, p. 538]". p. 19 gives a primary statement of φ(1/2): "if χ = 1 and ε = 0 then
Φ^Γ(1/2) equals minus the 2^v × 2^v identity matrix and thus Tr Φ^Γ(1/2) = −2^v". For N = 1 (v = 0)
this gives **φ(1/2) = −1**. For χ = 1, ε = 1, R = ∅ and there is no continuous-spectrum term: odd
forms have no continuous spectrum.

### 1.4 N = 1 specialisation, per parity (DERIVED from (2.39); mechanical)

For N = 1: q(χ) = 1, χ trivial and pure, d(1) = 1, every Π_{p|N} is 1, ⟨χ(δ)⟩ = 1,
log(N,2) = log 1 = 0, the last p | N/q sum is empty, C = 2 (ε = 0) or 0 (ε = 1), and {χ}_0 ≡ 2,
{χ}_1 ≡ 0. Define

* E2 := (1/8) ∫ h(r)/cosh(πr) dr. This is the t = 0 term: d = −4, |r[1]^1| = 4, arccos 0 = π/2, so
  A(0,1) = (1/4) ∫ e^{−πr}/(1+e^{−2πr}) h dr = (1/8) ∫ h/cosh(πr).
* E3 := (1/(3√3)) ∫ h(r) cosh(πr/3)/cosh(πr) dr. These are the t = ±1 terms: d = −3, |r[1]^1| = 6,
  arccos(1/2) = π/3. Each t gives (1/(3√3)) ∫ e^{−2πr/3}/(1+e^{−2πr}) h dr, and symmetrising in r gives this.
* H := Σ_{t∈Z, |t|≥3} W(t²−4) = 2 Σ_{t≥3} W(t²−4) (hyperbolic), and
  R := Σ_{t∈Z, t≠0} W(t²+4) = 2 Σ_{t≥1} W(t²+4) (glide reflections; t = 0 has sqrt 4 ∈ Q and is excluded), where
  W(D) := Σ_{f|ℓ} h+(r[f]) [r[1]^1 : r[f]^1] · log ε1 / sqrt(D) · g( 2 log( (|t| + sqrt D)/2 ) ), D = dℓ².

**Even sector (ε = 0).** The left side includes h(i/2) from λ = 0.
```
Σ_even h(r_j) = (1/24) ∫ r h tanh(πr) dr + (1/2)(E2 + E3) + (1/2) H + (1/2) R
              + (g(0)/4) log(π⁴/2) − (1/4π) ∫ h(r) [ ψ(1/2+ir) + 2 ψ(1+ir) ] dr + 2 Σ_{n≥2} Λ(n)/n · g(2 log n)
```
**Odd sector (ε = 1):**
```
Σ_odd h(r_j)  = (1/24) ∫ r h tanh(πr) dr + (1/2)(E2 + E3) + (1/2) H − (1/2) R
              − (g(0)/4) log 8 − (1/4π) ∫ h(r) ψ(1/2+ir) dr
```
For the even g(0) term: −(1/4)(log 8 − 2 log 2π²) = +(1/4) log(π⁴/2). ψ = Γ'/Γ throughout.

### 1.5 Full PSL(2,Z), and the φ'/φ form the brief asks for (DERIVED)

Adding the two sectors gives:
```
Σ_all h(r_j) = (1/12) ∫ r h tanh(πr) dr + E2 + E3 + H + g(0) log(π/2)
             − (1/2π) ∫ h ψ(1/2+ir) dr − (1/2π) ∫ h ψ(1+ir) dr + 2 Σ Λ(n)/n g(2 log n)
```
This is identical, term by term, to BL16 (2.5) at n = 1. That formula's √n ∈ Z line is
(1/12) ∫ r tanh(πr) h + g(0) log(π√n/2) + h(0)/4 − (1/2π) ∫ hψ(1+ir); the a-sum is
2ΣΛ/m g(−2 log m) − h(0)/4 − (1/2π) ∫ hψ(1/2+ir); the h(0) terms cancel.

To reach the φ'/φ form, use the identity BL16 attributes to Hejhal Vol. 2 p. 509
(SECONDARY-READ, verified numerically in §1.7):
```
(1/4π) ∫ h(r) φ'/φ(1/2+ir) dr = g(0) log π − (1/2π) ∫ h ψ(1/2+ir) dr − h(0)/2 + 2 Σ_{m≥1} Λ(m)/m g(2 log m),
φ(s) = ζ*(2(1−s))/ζ*(2s),   ζ*(s) = Γ_R(s) ζ(s),   Γ_R(s) = π^{−s/2} Γ(s/2)        (BL16 Prop 2.1, Thm 1.2)
```
By the functional equation ζ*(2−2s) = ζ*(2s−1), so φ(s) = ζ*(2s−1)/ζ*(2s) =
**sqrt(π) Γ(s−1/2) ζ(2s−1) / (Γ(s) ζ(2s))**, exactly the brief's form. Substituting gives

```
Σ_all h(r_j) = (π/3)/(4π) ∫ r h tanh(πr) dr                                    [identity, area π/3 → 1/12]
             + Σ_{hyp {P}} ln N(P0) / (N(P)^{1/2} − N(P)^{−1/2}) · g(ln N(P))   [= H, see §2]
             + (1/8) ∫ h/cosh(πr) dr + (1/(3√3)) ∫ h cosh(πr/3)/cosh(πr) dr     [elliptic, orders 2 and 3]
             + (h(0)/4)(1 − φ(1/2)) − g(0) ln 2 − (1/2π) ∫ h ψ(1+ir) dr         [parabolic; φ(1/2) = −1 → h(0)/2]
             + (1/4π) ∫ h(r) φ'/φ(1/2+ir) dr                                    [scattering, + sign on this side]
```

This has the same structure as BS07 (2.37) for χ = 1. There, |C|/2 · {h(0)/4 − g(0) log 2 −
(1/2π)∫hψ(1+ir)} − (1/4) h(0) Tr Φ(1/2) adds up to the h(0)/2 and −g(0) log 2 above.
**Every term in the brief's list is confirmed, with these exact constants:**

| term | brief | confirmed value |
|---|---|---|
| identity | (area/4π) ∫ r h tanh, area π/3 | 1/12 (full); **1/24 per parity** (BS07 (2.39): Π(p+1)/24 at N = 1) |
| hyperbolic | ln N(P0)/(N^{1/2} − N^{−1/2}) g(ln N(P)) | yes (BS07 (2.37) line 2 with det = +1; class weights in §2) |
| elliptic order 2 | – | **(1/8) ∫ h(r)/cosh(πr) dr** in total; half per parity |
| elliptic order 3 | – | **(1/(3√3)) ∫ h(r) cosh(πr/3)/cosh(πr) dr** in total (both t = +1 and t = −1, i.e. both rotation classes); half per parity |
| h(0)/4 [1 − φ(1/2)] | yes | = h(0)/2, since φ(1/2) = −1 (BS07 p. 19). It is all in the **even** sector: h(0)/2 even, 0 odd |
| −g(0) ln 2 | yes | yes in total; split −(1/4) g(0) ln 2 even, −(3/4) g(0) ln 2 odd (§3.3) |
| −(1/2π) ∫ h ψ(1+ir) | yes | yes in total; all of it in the even sector (§3.3) |
| +(1/4π) ∫ h φ'/φ(1/2+ir) | yes | yes; all of it in the even sector |

### 1.6 Per-class elliptic form (DERIVED consistency note)

The elliptic values above can be written as Σ_R 1/(2 m_R sin θ_R) ∫ e^{−2θ_R r}/(1+e^{−2πr}) h dr.
The sum runs over the PSL(2,Z) elliptic classes: one class of order 2 (θ = π/2, m = 2) and two classes
of order 3 (R and R², θ = π/3 and 2π/3, m = 3). m_R is the order of the centraliser in PSL(2,Z).
- Order 2: 1/(4·1) ∫ e^{−πr}/(1+e^{−2πr}) h = (1/8) ∫ h/cosh(πr).
- Order 3: 2 × 1/(2·3·(√3/2)) × (1/2) ∫ h cosh(πr/3)/cosh(πr) = (1/(3√3)) ∫ h cosh(πr/3)/cosh(πr).

Their contributions to the Weyl constant are 1/8 and 2/9, since ∫ 1/cosh(πr) dr = 1 and
∫ cosh(πr/3)/cosh(πr) dr = 2/√3 (both checked numerically to 1e-15).

> **Factor-of-2 trap, unresolved against Iwaniec.** I could not open Iwaniec Thm 10.2. Elliptic weights
> in the literature differ by factors of 2 depending on (i) whether m_R is the centraliser order in SL(2)
> or PSL(2), (ii) whether R and R^{−1} are counted separately, and (iii) whether the kernel is written as
> e^{−2θr}/(1+e^{−2πr}) or as cosh((π−2θ)r)/cosh(πr), which is twice it after symmetrisation. Use the values in
> the table above. They come from two primary formulas (BS07 (2.39), BL16 (2.5)) that agree with each
> other, and the per-parity Weyl law built from them matches the 600-form data (§5).

## 2. Length ↔ trace, and multiplicities

### 2.1 Norm and length (QUOTED)

- LZ01 p. 254: "N(γ) is defined as (1/4)(|tr(γ)| + sqrt(tr(γ)² − 4))² or equivalently as ε² where γ is
  conjugate in PSL(2,R) to ±(ε 0; 0 1/ε)." Primitive means "γ is not a power of any matrix of smaller trace".
- SY10 p. 1: "conjugate over SL(2,R) to (λ 0; 0 λ^{−1}) with λ > 1 … tr(P) = λ + λ^{−1}, and we define its
  norm to be N P = λ²."
- Bo03 p. 69 (secondary): "2 cosh(l_p/2) = |Tr M|".
- So **ln N(P) = 2 ln λ = 2 arccosh(|t|/2)**, with λ = (|t| + sqrt(t²−4))/2. This matches the g-argument
  in BS07 (2.40), log((|t| + sqrt(t²−4))²/4).
- Glide reflections (det −1, trace t ≠ 0) per BS07 (2.50): "N(T) = (1/4)(|t| + sqrt(t² − 4n))²" with n = −1,
  i.e. N = ((|t| + sqrt(t²+4))/2)². Then N^{1/2} + N^{−1/2} = sqrt(t²+4) (DERIVED).

### 2.2 Multiplicity in terms of class numbers

**Sarnak 1982, Prop. 4** (UNVERIFIED). As quoted in SY10 §2, pp. 3–4 (SECONDARY-READ):
> "Sarnak ([13], Proposition 4) showed that primitive hyperbolic conjugacy classes correspond to equivalence
> classes of primitive indefinite binary quadratic forms. … the automorphs of this form are ±P(t,u) where
> P(t,u) = ( (t−bu)/2  −cu ; au  (t+bu)/2 ), with t² − du² = 4 … If (t_d, u_d) denotes the fundamental solution
> to the Pell equation, then P(t_d,u_d) is a primitive hyperbolic matrix with trace t_d and norm ε_d² …
> for every discriminant d we see that there are h(d), the class number, primitive hyperbolic conjugacy
> classes and these all have the same trace t_d and norm ε_d²."
> "Ψ_Γ(x) = Σ_{2<t≤X} Σ_{d: t²−du²=4} h(d) log(ε_d²)", and with h(d) log ε_d = sqrt(d) L(1,χ_d):
> "Ψ_Γ(x) = 2 Σ_{2<t≤X} Σ_{du²=t²−4} sqrt(d) L(1,χ_d)."

Here d runs over all discriminants, not only fundamental ones, and h(d) counts SL(2,Z)-proper classes
of primitive forms (narrow class number).

**BS07, the primary counterpart** (PRIMARY-READ, pp. 20–22). With t² − 4n = dℓ² and
H_{n,t} = ⊔_{f|ℓ} C(T_t, r[f]) (2.54), eq. (2.58) at N = 1 gives
"|C(T_t, r[f]) // Γ̄+| = h+(r[f]) · {2 if d<0 ; 1 if d>0}". Lemma 2.10 (p. 21) gives
"log N(T0) = 2 [r[1]^1 : r[f]^1] · log ε1" for T0 generating the centraliser.
Ef93 p. 212 independently states that the number of cycles of reduced forms equals "the number of proper
equivalence classes of primitive forms of discriminant D (the narrow class number h1(D))".

**Multiplicity (DERIVED from BS07 (2.54), (2.58), Lemma 2.10).** The number of PSL(2,Z) hyperbolic
conjugacy classes, primitive or not, with |trace| = t ≥ 3 is

    g(t) = Σ_{f | ℓ} h+(d f²),   where t² − 4 = d ℓ², d fundamental.

Equivalently it is the number of SL(2,Z)-classes of all forms, imprimitive included, of discriminant
t² − 4. Each class P contributes ln N(P0) = 2[r[1]^1 : r[f]^1] log ε1, where f is the conductor of
its order. By Sarnak's correspondence, a class with trace t that belongs to discriminant D' = d f²
(t² − D'u² = 4, u = ℓ/f) is **primitive iff (t, u) is the fundamental solution** of the Pell equation
for D'. Otherwise it is a power of a primitive class with smaller trace. The D' = t² − 4 term (u = 1)
is always primitive, but it is not the only primitive one: at t = 6 the D' = 8 class (u = 2) is also
primitive, because (6, 2) is fundamental for D' = 8.

## 3. The desymmetrised (parity-split) trace formula

### 3.1 Primary statement

This is BS07 (2.39) with ε ∈ {0,1}, quoted in §1.3 and specialised in §1.4. The reflection (glide-reflection)
terms are exactly the n = −1 terms of line 2, with sign n^ε = (−1)^ε: **+ for even, − for odd**.
Their lengths and weights (QUOTED (2.40) at n = −1, t ≠ 0):

    A(t,−1) = log ε1 / sqrt(t²+4) · g( log( (|t| + sqrt(t²+4))² / 4 ) ),   t² + 4 = dℓ²

The class weight is Σ_{f|ℓ} h+(r[f]) [r[1]^1 : r[f]^1], with prefactor (1/2)(−1)^ε summed over t ∈ Z∖{0}.
In (2.37) form, each glide-reflection class contributes log N(T0)/[Z:[T0]] · g(log N)/(N^{1/2} + N^{−1/2}).
The **pure reflections** (t = 0, det −1, sqrt(4) ∈ Q) are excluded from the class sum (BS07 p. 20:
"M does not contain any reflections"). Their effect sits in the parity-dependent g(0), ψ, Λ and h(0)
terms of lines 4–6.

### 3.4 Second primary statement: BL16 at n = −1 (QUOTED, PRIMARY-READ (2.5), from Strömbergsson 2016)

BL16 states the trace formula for T_n with n < 0. T_{−1} is the parity operator: in the proof of their Thm 1.1 (§4), Tr T_{−n}

### 3.5 Discrepancies and errata noted by the sources

- **BS07 Remark 2.6 (p. 14, QUOTED):** (2.37) "specializes to the formula [Venkov, (6.5.40)], after the latter
  has been slightly modified in its next to last line to correct for two minor errors (note that these mistakes

- BGGS92/97 and BSS92 write the desymmetrised formula in physicist notation. I could not open them
  (UNVERIFIED), so I cannot report whether their reflection weights or g(0) constants differ from BS07.

## 4. Mayer's transfer operator and parity

**Operator** (Ma91 p. 57 eq. (1); Ef93 p. 208; LZ01 (4.20), QUOTED):
(L_s f)(z) = Σ_{n≥1} (1/(n+z))^{2s} f(1/(n+z)). It acts on functions holomorphic in |z − 1| < 3/2 and
continuous on the closure, for Re s > 1/2, and is continued meromorphically (Ma91 Thm 1; LZ01 (4.21)).

**Factorisation** (Ma91 Theorem 2, p. 59; Ef93 (0.3); LZ01 (4.22), QUOTED): **Z(s) = det(1 − L_s) det(1 + L_s)**,
with Z(s) = Π_{{γ} primitive} Π_{m≥0} (1 − N(γ)^{−s−m}) (LZ01 (4.19)).

**Parity assignment, the decisive quotes:**
- Ef93 p. 209 Corollary: "det(1 − L_s) = 0 if and only if s is even; det(1 + L_s) = 0 if and only if s is odd."
  Here "s is *even* if s(1−s) is an eigenvalue of an even eigenfunction or else if ζ*(2s) = 0", and odd means
  f(−x, y) = −f(x, y). Also: "Δ restricted to L²_odd is of purely discrete spectrum, while the continuous
  spectrum of Δ belongs in L²_even".
- Ef93 p. 210 Theorem: det(1 − L_s) = Z_+(s), det(1 + L_s) = Z_−(s), where
  Z_±(s) = Π_{{{g}}_{Γ'}, det g=1} Π_ℓ (1 − N(g)^{−s−ℓ}) · Π_{{h}_{Γ'}, det h=−1} Π_ℓ (1 ∓ (−1)^ℓ N(h)^{−s−ℓ}),
  Γ' = PGL(2,Z), N(h) := N(h²)^{1/2}. The det −1 (glide-reflection) classes enter with **opposite signs** in
  the two factors, which is the dynamical counterpart of §3.
- LZ01 p. 255: "Z(s) has a natural splitting Z+(s)Z−(s) … Z+(s) and Z−(s) have zeros at the spectral parameters
  of Γ corresponding to even and odd Maass forms, respectively, and one in fact has Z±(s) = det(1 ∓ L_s)."
  Corollary: "a) there exists a nonzero h ∈ V with L_s h = −h iff s is the spectral parameter corresponding to
  an odd Maass wave form; b) … L_s h = h iff s is either the spectral parameter corresponding to an even Maass
  form, 2s is a zero of the Riemann zeta function, or s = 1." (Re s > 0, s ≠ 1/2.)
- **Conclusion: eigenvalue +1 of L_s ↔ even (plus ζ(2s) zeros and s = 1); eigenvalue −1 ↔ odd.** This
  agrees with the project's finding "+1 ↔ even = sym0".
- **Superseded statement:** Ma91 p. 59 speculated the opposite: "all the eigenvalues of −Δ are determined
  by the factor det(1 − L_s) whereas the nontrivial zeros of Riemann's zeta function are determined by
  det(1 + L_s)". Efrat's and LZ's theorems refute this. Do not cite Ma91 for the parity assignment.

**Traces with the (−1)^n sign** (Ef93 p. 210, QUOTED, attributed to Mayer [M1]):
```
tr(L_s^n) = Σ_{a1..an ≥ 1} Π_{i=1}^n [0; overline{a_i,…,a_n,a_1,…,a_{i−1}}]^{2s}
                              / ( 1 − (−1)^n Π_{i=1}^n [0; overline{a_i,…,a_{i−1}}]² )
          = Σ_{T^n x = x} P_n(x)^s / (1 − (−1)^n P_n(x)),   P_n(x) = Π_{i=1}^n (T^i x)²,  T(x) = {1/x}.
```
Ma91 Prop. 1 (p. 57) gives the equivalent Z_n(T_G, A_s) = trace L_s^n − trace(−L_{s+1})^n, with
Z_n = Σ_{x∈Fix T^n} exp Σ_k A_s(T^k x) and A_s(x) = −s log|T'(x)| = s log x². Ef93 p. 211 (1.1)
splits −d/ds log det(1 − L_s) by **even and odd minimal period m**:
denominators 1 − P_m(x)^k for m even and 1 − (−1)^k P_m(x)^k for m odd. Ef93 p. 212 shows that a
period-M reduced cycle whose form Q is properly equivalent to its opposite Q* has M/2 odd. Odd-period
continued fractions are the glide-reflection (det −1) classes, and P_m(x) = Π_{i=1}^{M/2} W_i^{−2}.
Ma91 p. 59: "Z_n(T̃_G, Ā_s) = 0 for n odd and Z_n(T̃_G, Ā_s) = 2 Z_n(T_G, A_s) for n even", which gives
Z(s) = det(1 − L_s²) (Ef93 p. 208).
