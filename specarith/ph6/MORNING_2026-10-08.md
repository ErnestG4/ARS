## Decisions for Will
1. **C3b (E-linked torus) — proposed INAPPLICABLE.** BEK §5 (eqs. 5.2–5.3) reads each matrix size N only near one
   energy E(N) = π√(2N) − 2π (K nearest levels); every N is a different spectrum. A single ≥ 3·10⁴-level list would need
   stitching levels from different matrices up to N ≈ 7·10⁶ — a construction the paper does not define.
2. **C3a's N.** BEK Lemma 1 (spectrum symmetric about 0 when ℓ_x = ℓ_ξ) means N = 3·10⁴ gives 15,001 positive levels —
   below the ≥ 3·10⁴ rule if, as for the zeros, only E > 0 counts. Options: (a) N = 6·10⁴ (recommended; prepared — see
   status), (b) count both signs at N = 3·10⁴ (not recommended: the negative half is a mirror image), (c) keep N = 3·10⁴
   and C3a reads NOT RESOLVABLE.
3. **T2/T4 known-answer check on the zeros** — pending the full matched-size bands (running on spot); if the zeros fail
   the 6.1 rules as written, a proposed amendment will be here (not applied). **Preliminary:** the zeros' ⟨r̃⟩ over the
   first 3·10⁴ is 0.6129 (thirds: 0.6147 / 0.6121 / 0.6120); one matched-size GUE draw gives 0.5981 (finite-window GUE
   sits ~0.0015 below the large-N 0.5996, as ARS-RH Phase 1 also found). With a band SD of order 0.002 the zeros will
   sit far above the GUE band — the low-height excess ARS-RH Phase 1 resolved. If confirmed, the 6.1 text's T2 ("inside
   both bands") fails the zeros' own known answer, and T4's "inside exactly one band" classifies them as no class.
