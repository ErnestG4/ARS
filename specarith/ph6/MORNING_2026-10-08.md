## Decisions for Will
1. **C3b (E-linked torus) — proposed INAPPLICABLE.** BEK §5 (eqs. 5.2–5.3) reads each matrix size N only near one
   energy E(N) = π√(2N) − 2π (K nearest levels); every N is a different spectrum. A single ≥ 3·10⁴-level list would need
   stitching levels from different matrices up to N ≈ 7·10⁶ — a construction the paper does not define.
2. **C3a's N.** BEK Lemma 1 (spectrum symmetric about 0 when ℓ_x = ℓ_ξ) means N = 3·10⁴ gives 15,001 positive levels —
   below the ≥ 3·10⁴ rule if, as for the zeros, only E > 0 counts. Options: (a) N = 6·10⁴ (recommended; prepared — see
   status), (b) count both signs at N = 3·10⁴ (not recommended: the negative half is a mirror image), (c) keep N = 3·10⁴
   and C3a reads NOT RESOLVABLE.
3. **The zeros FAIL their own known answer under the 6.1 T2 and T4 rules as written — proposed amendment PA-6.1-1
   (NOT applied).** Matched-size bands (W = 3·10⁴, 200 draws each; `results/preread61/bands61.json`,
   `redpaths61.json`): means Poisson 0.38620, GOE 0.53090, GUE 0.59991, GSE 0.67436 — each within 0.0003 of the Atas
   large-N label (an independent check of D4's values); SDs 0.0015–0.0020.
   - **Zeros (first 3·10⁴): ⟨r̃⟩ = 0.61293 = GUE band + 8.5 SD** (GSE −40 SD, GOE +46 SD). This is the low-height excess
     ARS-RH Phase 1 resolved (it falls with height: thirds 0.6147 / 0.6121 / 0.6120). So T2 as written ("inside both
     bands") FAILs the zeros, and T4 as written ("inside exactly one band") gives no class.
   - **Red paths:** nearest band mean (in band-SD units, leave-one-out bands) classifies 800/800 draws correctly; the rule
     as written leaves 11–12 of 200 per ensemble unclassified (≈ 6%: inherent to 95% bands — a second defect).
   - **Picket fence:** ⟨r̃⟩ = 1 (crystal), as required.

   **PA-6.1-1 (proposal):** (i) **T2** — the sealed reference is the zeros at matched height (D5) alone: PASS iff the
   candidate's ⟨r̃⟩ lies in the zeros' band (block-bootstrap CI over the T1-matched range); the GUE band is reported
   descriptively (at these heights the zeros themselves sit +8.5 SD above it). (ii) **T4** — nearest class by
   |⟨r̃⟩ − band mean| / band SD, assigned when the nearest is separated from the second-nearest by ≥ 3 SD units, else
   "ambiguous" (NOT RESOLVABLE); integrable crystals INAPPLICABLE as before. Known answers under (ii): zeros → GUE
   (8.5 vs 40.0); 800/800 draws → their own class. Under the rules as written the instrument would fail its own known
   answer, so 6.1 should not be sealed without a decision here.
