# TRANSLATION TABLE — ARS home dialect ↔ Ripley/Baddeley spatial-statistics atlas

**Arc:** Bridge (2026-08-14). **Rule (tripwire 5):** every Observer-B object cited here is
implemented once in our own code (`bridge/observer_b.py`) and cross-checked against spatstat
(`bridge/spatstat_xcheck.R`); no black-box rows. **Dimension tags per tripwire 2** — every
relation states its 1D and 2D forms where they differ; the dominant error mode is a correct
value in the wrong dimension slot.

Conventions: home dialect works in **unfolded, unit-mean-spacing units** (intensity 1);
spatial dialect works in **raw coordinates with explicit intensity λ**. The transition between
them is exactly one normalization: `s = r·λ` (1D) / `s = r·√λ` (2D, per-axis length scaling).
One transition per data path (tripwire 1).
